# Prompt de trabajo — v0.2

Alcance de DESIGN.md §9 para v0.2: dashboard propio, gVisor, cosign, UniFi, restic, LXC de
Proxmox y dominio real con DNS challenge. Orden por valor para el homelabber y por lo que se
puede verificar en las VMs.

## Decisiones (DESIGN.md §11)

- **"Dashboard propio" = panel de estado en Grafana**, no una web nueva. `guardianctl doctor
  --json` se ejecuta por timer y Vector lo ingiere; un dashboard provisionado "Guardian · Estado"
  muestra comprobaciones, versiones y última copia. Evita una segunda superficie de autenticación.
- **Copias con restic**: `backup:` en `guardian.yaml` (repositorio local o remoto, contraseña en
  el vault, planificación). `guardianctl backup init|run|list|restore` y timer de systemd.
  Se copian `guardian.yaml`, `compose/.env`, `vault/`, `compose/certs/` y los volúmenes Docker
  (Postgres con `pg_dump`; el resto como tar desde un contenedor efímero de solo lectura).
- **cosign keyless en GitHub Actions**: el workflow de release construye, firma artefactos
  (`cosign sign-blob`, identidad OIDC del workflow) y publica `.sig`/`.pem`; `install.sh`
  verifica con `cosign verify-blob` si cosign está instalado y sigue exigiendo SHA-256 siempre.
  No se verifican firmas de imágenes upstream (no todas están firmadas); se mantienen los digests.
- **gVisor para agentes**: `install.sh --with-gvisor` instala `runsc` desde el repositorio apt
  oficial de gVisor (clave verificada) y lo registra en Docker; el manifiesto admite
  `sandbox.runtime: gvisor` (por defecto `runc`). `agent run` falla claro si se pide gVisor y
  no está. `userns-remap` queda descartado definitivamente (gVisor cubre el objetivo).
- **Dominio real**: `tls: {mode: internal|acme-dns, provider: cloudflare, email}` en
  `guardian.yaml`; imagen de Caddy propia (`compose/caddy/Dockerfile` con `xcaddy` y el módulo
  DNS) construida en local con base fijada por digest. Token del proveedor solo en `.env`.
  Solo se puede verificar la configuración (`caddy validate`); la emisión real la prueba el beta.
- **UniFi**: guía renderizada como OPNsense. **Proxmox LXC**: guía + comprobaciones en `doctor`
  (nesting, módulo wireguard, AppArmor en el contenedor).

## Criterios de aceptación

- `backup run` crea un snapshot con todo lo listado y `backup restore --to <dir>` lo recupera;
  el timer lo repite; `doctor` avisa si la última copia tiene más de N días.
- El workflow de release deja tarball, binarios, `SHA256SUMS` y firmas; `cosign verify-blob`
  las acepta con la identidad del workflow.
- `hello-agent` corre con `sandbox.runtime: gvisor` y pasa su prueba de humo; `docker inspect`
  muestra `Runtime=runsc`.
- `tls.mode: acme-dns` genera un Caddyfile válido y la imagen construye; el modo `internal`
  sigue siendo el predeterminado y no cambia nada para v0.1.
- Dashboard "Guardian · Estado" con el último `doctor` y la última copia.
- `policy render unifi` sin marcadores sin sustituir. CI en verde.

## Restricciones

Las de v0.1. Ningún puerto nuevo. Nada de `curl | bash` (gVisor y restic vienen de apt con
claves verificadas). Las imágenes propias se construyen desde bases fijadas por digest.
